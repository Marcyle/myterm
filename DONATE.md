# Donate

If MyTerm helps your daily database or remote operations work, you can support the project with a small donation. Donations help cover maintenance time, cloud services, infrastructure, and continued feature work.

Donation is optional. All MyTerm features remain available whether you donate or not.

## How Donations Are Used

- Cloud services and infrastructure
- New features and experience improvements
- Long-term maintenance

## Other Ways To Help

- Star the repository
- Report bugs or request features
- Share MyTerm with people who may need it
- Submit focused pull requests
